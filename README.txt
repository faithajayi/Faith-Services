FAITH SERVICES — GITHUB PAGES READY WEBSITE

This package is designed to avoid missing assets folders. All CSS and JavaScript are embedded directly in each HTML page.

FILES TO UPLOAD TO THE ROOT OF YOUR EXISTING GitHub repository Faith-Services:
- index.html
- about.html
- services.html
- sectors.html
- contact.html
- CNAME

HOW TO UPDATE:
1. Extract this ZIP on your computer.
2. Open https://github.com/faithajayi/Faith-Services
3. Click Add file > Upload files.
4. Drag the SIX files listed above into the upload area. Do not upload the README if you do not want to replace the existing README.
5. Commit changes to the main branch.
6. Keep GitHub Pages configured to deploy from main / (root).
7. The CNAME file should contain faithservicesuk.co.uk.

No assets folder is required. All CSS and JavaScript are embedded in the HTML files.
